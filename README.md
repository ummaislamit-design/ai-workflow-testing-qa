# AI Workflow Testing (QA Project)

This project demonstrates hands-on QA testing of AI/LLM-driven workflows, focusing on output validation, edge cases, and real user behavior.

## 🔍 Scope
Tested prompt-based AI responses across:
- Accuracy & correctness
- Consistency across repeated inputs
- Edge cases & ambiguous prompts
- Hallucinations & incorrect outputs
- UX clarity and usefulness

## 🧪 Testing Types
- Exploratory Testing
- Functional Testing
- Regression Testing (AI response consistency)
- API Testing (request/response validation)

## 🛠 Tools Used
- Postman (API testing)
- Browser DevTools (network inspection)
- JSON validation
- Manual testing techniques

## 🔄 Workflow Tested
User Input → API Request → AI Response → UI Display

## 📁 Project Structure
- /test-cases → Structured QA test cases
- /bug-reports → Realistic bug reports
- /checklists → Regression checklist for AI features

## 🎯 Key QA Focus
- Detecting hallucinations
- Validating response reliability
- Testing prompt sensitivity
- Ensuring consistent behavior across inputs

## 🚀 Outcome
Improved understanding of testing AI-driven systems and identifying non-deterministic defects.
